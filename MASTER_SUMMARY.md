## 📋 Quick Start Guide

### Right Now: Get Images

**Option 1: Unsplash (Fastest - 2 hours)**
1. Visit: https://unsplash.com
2. Search collections in `IMAGE_STRATEGY.md`
3. Download "Large" size images
4. Save to `/public/projects/[project]/`
5. Name: hero.jpg, identity.jpg, interface-1.jpg, interface-2.jpg, detail.jpg

**Option 2: AI Generation (Custom - 3 hours)**
1. Use prompts from `IMAGE_STRATEGY.md`
2. Generate with Midjourney or DALL-E
3. Download and optimize
4. Save to project directories

**Option 3: Mix Both (Balanced - 2.5 hours)**
1. Unsplash for photography
2. Figma for interface mockups
3. Combine for complete sets

### Next: Deploy

